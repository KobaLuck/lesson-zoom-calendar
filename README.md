# Урок: Zoom + Google Календарь

Локальное приложение для репетитора на **Windows, macOS и Linux** и скрипт для **iPhone / Scriptable**. Создаёт Zoom-встречу, добавляет урок в Google Календарь и готовит сообщение ученику с настоящей ссылкой на созвон.

## Возможности

- Выбор даты, времени, длительности и предмета: математика, информатика и другие.
- Подстановка имени, времени и ссылки на доску Холст в редактируемый текст сообщения.
- Московское время по умолчанию; отдельный часовой пояс ученика.
- Инструкция по доске, проверке камеры и звука; просьба заранее предупреждать об опоздании, отмене и переносе.
- Создание Zoom-встречи с залом ожидания, подстановка ссылки участника и кода доступа.
- Добавление события в Google Календарь с той же Zoom-ссылкой.
- Повтор добавления в календарь без создания новой Zoom-встречи.
- Сохранение учеников и последнего сообщения отдельно на каждом устройстве.

Сообщение копируется вручную: приложение не отправляет его ученику и не рассылает приглашений по email.

## Совместимость

| Платформа | Текущее состояние |
| --- | --- |
| macOS | Проверено создание настоящей встречи и события |
| Windows | Системное хранилище ключей, запуск через `.bat` |
| Linux | Хранилище Secret Service, запуск через `.sh` |
| iPhone / Scriptable | Встроенные формы Scriptable без WebView; проверены на имитациях, нужен запуск на устройстве |

Сообщение копируется средствами браузера. Секреты хранятся в системном защищённом хранилище: Keychain на macOS, Windows Credential Locker на Windows, Secret Service (например, GNOME Keyring) на Linux. В Linux нужен работающий и разблокированный Secret Service в пользовательском сеансе. Незашифрованное хранение ключей не используется.

## Запуск на Windows

Нужен Python 3.9+ с [python.org](https://www.python.org/downloads/). В терминале из папки проекта:

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Затем дважды нажмите **Запустить.bat**. Он использует Python из `.venv`, если окружение создано, иначе системный `py -3`.

## Запуск на Linux

Нужен Python 3.9+, модуль venv и рабочий Secret Service (например, GNOME Keyring). В терминале из папки проекта:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
sh Запустить.sh
```

Если создание окружения недоступно, установите пакет venv для вашего дистрибутива (на Ubuntu/Debian — `python3-venv`). Если хранилище ключей заблокировано или отсутствует, приложение покажет подсказку; ключи в обычный файл не сохраняются. Для работы нужен графический сеанс с браузером.

## Запуск на Mac

Нужен **Python 3.9+**. На macOS дополнительные пакеты не требуются; прежние настройки Keychain совместимы с обновлением.

1. Скачайте репозиторий и распакуйте в отдельную папку.
2. Дважды нажмите `Запустить.command`. Оставьте окно запуска открытым.
3. Заполните настройки Zoom и Google-скрипта.
4. Заполните данные урока, проверьте сообщение и нажмите «Создать Zoom, событие и сообщение».

Форма работает на вашем компьютере и слушает только `127.0.0.1`. HTML-файл отдельно открывать не нужно.

## Запуск на iPhone

Скопируйте весь файл `Урок-Zoom-Scriptable.js` в скрипт приложения Scriptable. При обновлении полностью замените старый код. Настройки и история в Keychain сохраняются.

iPhone-версия использует **встроенную таблицу Scriptable**, без HTML и WebView. Нажимайте строки, чтобы выбрать ученика, предмет, дату, время, длительность и доску. По умолчанию время московское; календарь и часы выбираются стандартными средствами iOS. Для другого пояса ученика можно указать актуальное на дату урока смещение от UTC.

- «Посмотреть сообщение» открывает предпросмотр текста.
- Для ручной правки скопируйте шаблон, отредактируйте его в Заметках и верните через «Вставить свой текст из буфера», сохранив `[ССЫЛКА ZOOM]`.
- «Создать Zoom, событие и сообщение» выполняет запросы к сервисам.
- «Скопировать сообщение» копирует готовый текст с Zoom-ссылкой.

Подключения на телефоне заполняются через «Настройки подключения». До показа таблицы нет сетевых запросов. Прежний WebView-интерфейс заменён после сообщений о зависании и пустом экране; запуск на конкретном iPhone требует проверки пользователем.

## Подключение сервисов

Подробные шаги: **[Инструкция.md](Инструкция.md)**.

- **Zoom:** приложение Server-to-Server OAuth с разрешением **`meeting:write:meeting:admin`**. В разделе Scopes выберите **Meetings → Create a meeting for a user**, а не разрешения раздела Accounts. Приложение должно быть активировано.
- **Google Календарь:** разверните `Google-Календарь.gs` как веб-приложение Apps Script, подключите Calendar API v3 и используйте `appsscript.json`. Выполнять от имени владельца; доступ «Все». Запросы защищаются отдельным секретным ключом.
- **Холст:** укажите ссылку на конкретную доску с правом редактирования для ученика. Доски автоматически не создаются.

Ключи Zoom и Google-скрипта сохраняются в системном хранилище устройства. Список учеников и история на ПК хранятся в `.lesson-zoom.json`, который исключён из Git. У каждого пользователя должны быть собственные настройки сервисов.

## Проверки

```sh
python3 tests/test_mac.py
python3 tests/test_platforms.py
node tests/test_template.mjs
node tests/test_scriptable.mjs
```

GitHub Actions запускает проверки на Windows, macOS и Linux. Они проверяют логику на этих ОС и адаптеры хранилищ с имитациями; это не заменяет проверку реального хранилища в графическом сеансе каждой системы.

Проверки работают на имитациях ответов сервисов, не обращаются к личным ключам и не создают встречи. Проверяются подстановка ссылки, часовые пояса, шаблон, сохранение ученика и повтор после ошибки Google без второй Zoom-встречи.

1 ноября 2026 года версия для Mac также проверена с настоящими Zoom и Google Календарём: встреча и событие создались, ссылка и код доступа попали в сообщение; тестовые объекты после проверки удалены. Версия Scriptable требует проверки на настоящем iPhone.

Тарифные ограничения Zoom сохраняются. Кастомные эмодзи Telegram через обычный текстовый буфер не передаются; стандартные эмодзи поддерживаются.
